# Josh Bailey · [@anarkiwi](https://github.com/anarkiwi)

Networks, radios, Tesla coils, and 8-bit sound. Wellington, NZ · [vandervecken.com](https://www.vandervecken.com)

Engineer/experimenter — 14 yrs at Google (network research/SDN), independent since 2019; consultant + hardware hacker. `Python · C · C++ · Go · 6502/68HC11 asm · LiteX/Migen`

### Selected open source work
- **SDN/Networking** — founding contributor to [FAUCET](https://github.com/faucetsdn/faucet) (production OpenFlow controller); [dovesnap](https://github.com/anarkiwi/dovesnap) (Docker OVS plugin), [pipette](https://github.com/anarkiwi/pipette) (SDN/NFV coprocessor), [faucetconfrpc](https://github.com/anarkiwi/faucetconfrpc). FAUCET deployed/cited by [NATO STO coalition tactical networks](https://www.sto.nato.int/document/a-software-defined-networking-architecture-for-coalition-tactical-military-networks/) (ICMCIS 2025), [Sandia National Laboratories](https://conference.faucet.nz/assets/files/Timothy+Toole+-+FAUCET+at+Sandia+National+Laboratories.pdf) (2019), and [IQT Labs *Defensive 5G*](https://forum.defcon.org/filedata/fetch?id=243179&d=1660004109) (DEF CON 30, 2022). Also [colatrl](https://github.com/colatrl/colatrl) (eBPF [CLAT](https://datatracker.ietf.org/doc/html/rfc6877)/464XLAT, originally by Maciej Żenczykowski), [Wireshark](https://www.wireshark.org) contributor (IPDC dissector, Lucent/Ascend trace parsing).
- **RF/SDR/radar** — maintainer of [gamutRF](https://github.com/IQTLabs/gamutRF) (SDR scanner/collector); [samples2djidroneid](https://github.com/anarkiwi/samples2djidroneid) (DJI DroneID from I/Q); [canny-valley](https://github.com/anarkiwi/canny-valley) (Linux control and rail SAR imaging for a 2.4 GHz FMCW radar kit); [pic2iq](https://github.com/anarkiwi/pic2iq) (images as I/Q spectrograms); [pysigsaly](https://github.com/anarkiwi/pysigsaly) (emulator of SIGSALY, Bell Labs' 1943 digital secure voice system).
- **FPGA** — [reefervole](https://github.com/anarkiwi/reefervole) (LiteX dev framework for the Colorlight 5A-75B, all-open-source flow), [c0neify](https://github.com/anarkiwi/c0neify) (DeMiSTify target so MiST cores run on the Commodore One).
- **ML** — RF signal classification (gamutRF), [sentinel-solver](https://github.com/anarkiwi/sentinel-solver) (automated solver for *The Sentinel*).
- **Tesla coils** — [chime_red2](https://github.com/anarkiwi/chime_red2) (musical Tesla coil controller, MIDI-driven), [midivoder](https://github.com/anarkiwi/midivoder) (voice to MIDI vocoder, sings through it), [third-light](https://github.com/anarkiwi/third-light) (SSTC/DRSSTC/QCW multiphysics simulator, CUDA-accelerated).
- **Glitch/graphics** — [rutt-etra-cv2](https://github.com/anarkiwi/rutt-etra-cv2) (Rutt/Etra scan processor as an OpenCV filter), [nbtvencoder](https://github.com/anarkiwi/nbtvencoder) (software televisor: NBTV encode/decode to WAV), [pyvmancer](https://github.com/anarkiwi/pyvmancer) + [syncsummoner](https://github.com/anarkiwi/syncsummoner) (LZX Videomancer driver and characterization/generative video); Vectrex/PiTrex: [vekterm](https://github.com/anarkiwi/vekterm) (baremetal PiTrex vector receiver), [pyvterm](https://github.com/anarkiwi/pyvterm) (drives it from Python).
- **Reverse engineering / emulation** — [deity-informant](https://github.com/anarkiwi/deity-informant) (6502 decompiler with illegal opcodes: Ghidra P-Code lifter, VM, `.sid` playroutine decompiler), [jennings](https://github.com/anarkiwi/jennings) (py65-compatible MPU/assembler with cycle-exact illegal opcodes), [vagrant-moses](https://github.com/anarkiwi/vagrant-moses) (standalone C64 machine model: VIC-II, CIAs, cycle-exact 6510, KERNAL traps), [m68hc11](https://github.com/anarkiwi/m68hc11) (cycle-counting 68HC11 emulator), [pyvacs](https://github.com/anarkiwi/pyvacs) (Signetics 2650 assembler/disassembler), [nybulah](https://github.com/anarkiwi/nybulah) (raw-track imaging/writing of copy-protected disks on 1541/1571/1581 drives).
- **KIM-1** — [kimtape](https://github.com/anarkiwi/kimtape) (paper-tape loader over the stock monitor), [kimdos](https://github.com/anarkiwi/kimdos) (Commodore IEC disk access library and shell), [kimformer](https://github.com/anarkiwi/kimformer) (Z-machine: plays Zork from SD card).
- **C64 / chiptune** — [Vessel](https://github.com/anarkiwi/vessel) (high-performance C64 MIDI interface), [ulytiterm](https://github.com/anarkiwi/ulytiterm) (VT102/ANSI terminal with TCP and ACIA transports), [asid-vice](https://github.com/anarkiwi/asid-vice) (VICE with ASID support) + [revice](https://github.com/anarkiwi/revice) (its features as VICE-independent, unit-tested C libraries); pure-Python tracker readers/writers/players that also decompile `.sid` back to songs: [pygoattracker](https://github.com/anarkiwi/pygoattracker), [pysidwizard](https://github.com/anarkiwi/pysidwizard), [pydefmon](https://github.com/anarkiwi/pydefmon); [unitracker](https://github.com/anarkiwi/unitracker) + [grammar](https://github.com/anarkiwi/unitracker-grammar) + [player](https://github.com/anarkiwi/unitracker-player) (player-agnostic SID tracker document: lifts tunes from any tracker, optimises them, plays and builds `.sid`); [sidtrace](https://github.com/anarkiwi/sidtrace) (sidplayfp with cycle-annotated SID write logging).
